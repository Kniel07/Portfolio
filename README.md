# Kirk Ranches — Portfolio

Static single-page portfolio site. Plain HTML/CSS/JS, no build step, deployed via GitHub Pages.

## Structure
- `index.html` — page structure and content
- `css/styles.css` — design system (colors, type, layout)
- `js/script.js` — scroll-spy nav, scroll reveal, résumé download menu, hidden résumé-template picker
- `resume/` — versioned résumé source and archive (see `resume/README.md`); `resume/current/resume.pdf` and `resume/current/resume.docx` are the downloadable résumé files linked from the page

## Local preview
Just open `index.html` in a browser, or serve the folder with any static file server.
